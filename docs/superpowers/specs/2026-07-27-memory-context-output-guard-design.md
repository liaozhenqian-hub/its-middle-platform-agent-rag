# 记忆上下文输出隔离设计

## 问题

运行时会将历史会话摘要和已确认长期记忆拼接到当前用户问题之前。该文本用于模型推理，但模型可能原样复述输入。当前公开输出过滤器只处理内部 citation ID，无法识别记忆上下文，因此网页和飞书都可能展示内部摘要、记忆类型及当前问题包装结构。

## 设计

保留现有记忆召回与模型输入，不改变用户记忆功能。为记忆块增加明确的内部使用约束，禁止模型复述标题、记忆类型或内容列表。同时在所有渠道共用的 `sanitize_public_answer` 和 `PublicAnswerStream` 中识别行首内部标记，包括“历史会话摘要”“已确认的长期记忆”“相关历史上下文”以及内部记忆类型标签。

非流式输出在首次出现内部标记前截断；如果回答从内部标记开始，则返回统一安全提示。流式输出在尚未确定前缀是否安全时保留少量字符，支持标记跨 delta 分片；一旦确认泄漏，本轮不再输出原文，并在 flush 时仅输出一次安全提示。正常回答继续实时流式输出。

## 验证

测试覆盖非流式完整提示回显、内部块出现在正常文本之后、Markdown 标题包装、记忆类型直接回显、流式标记跨分片和正常流式回答。Agent 服务仍向模型传入记忆上下文，但最终 `AgentRunResponse.answer` 与 SSE delta 均不得包含内部标记。
